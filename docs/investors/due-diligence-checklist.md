# Minx — Investor Due-Diligence Checklist

Use status values: Not started / In progress / Verified / Not applicable. Assign an owner, date and evidence link to each item. Do not mark an item verified without evidence.

| Area | Evidence to collect | Status | Owner / evidence |
|---|---|---|---|
| Corporate and statutory | Certificate of incorporation, current company extract, constitution, registers, statutory filings, beneficial ownership records and board resolutions | Not started | |
| Cap table and equity | Fully diluted cap table, shareholder agreements, founder instruments, option pool if any, prior financing, liens and related-party interests | Not started | |
| IP and ownership | Founder/contractor IP assignments, domain ownership, trademarks, open-source licence inventory and access ownership | In progress | |
| Product | Approved PRD, architecture, ADRs, roadmap, UX prototypes and product demos | In progress | |
| Technology and security | Repository and cloud access map, CI/CD, backup/restore evidence, threat model, penetration-test plan/results, vulnerability register and incident response | In progress | |
| Commercial | Market-sizing methodology, competitor analysis, customer discovery, creator/merchant pipeline, LOIs, pilot agreements and pricing tests | Not started | |
| Financial | Editable 36-month model, assumptions register, programme budget, monthly actuals when available, cash runway and sensitivities | In progress | |
| Revenue partners | Payment-provider agreements, settlement terms, media/RTC/cloud quotations, SLAs and partner correspondence | Not started | |
| Regulatory and privacy | Kenyan legal advice, data protection assessment, privacy notices, terms, moderation/age policies, consumer protection review and any required approvals | Not started | |
| Team and operations | Founder/contractor CVs and agreements, role descriptions, payroll assumptions, support/moderation SOPs and incident logs | Not started | |
| Traction and KPIs | Beta cohort data, MAU/DAU, retention, watch hours, GMV, conversion, creator earnings, merchant activation, CAC and trust/safety metrics | Not started | |
| Investor process | Q&A log, NDA if appropriate, term sheet, approvals and closing checklist | Not started | |

## Sharing controls
- Share only with approved recipients; prefer view-only access.
- Never upload passwords, API keys, tokens, signing keys or customer personal data.
- Redact third-party confidential information unless disclosure is authorised.
- Record access grants and revocations.
- Provide aggregated, privacy-safe traction and financial reporting.
- Preserve approved final versions and mark drafts clearly.
- Obtain counsel review of NDAs, term sheets, securities documents and public fundraising claims.
